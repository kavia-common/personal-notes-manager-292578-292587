Personal Notes Manager - Shortcuts and Theme

Keyboard Shortcuts
- Ctrl/Cmd + N: Create a new note
- Ctrl/Cmd + S: Save now (flush autosave)
- Delete: Delete the current note (with confirmation)

Theme
- Ocean Professional theme using CSS variables in src/styles.css
- Primary: #2563EB, Secondary/Success: #F59E0B, Error: #EF4444
- Responsive single-page layout with header, sidebar, and editor.
